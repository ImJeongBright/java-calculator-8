## 주요 기능

* 기본 구분자 지원: 쉼표(,)와 콜론(:)을 사용해 숫자를 분리하고 합을 구합니다.

* 커스텀 구분자 지원: //와 \n 사이에 정의된 단일 문자를 사용자 지정 구분자로 사용합니다.

* 빈 값 처리: null이나 빈 문자열("")이 입력될 경우 0을 반환합니다.

## 예외 처리

다음과 같은 잘못된 입력 값에 대해서는 IllegalArgumentException을 발생시킵니다.

* 숫자에 음수가 포함된 경우

* 숫자로 변환할 수 없는 문자가 포함된 경우

* 커스텀 구분자 형식이 올바르지 않은 경우 (e.g., \n 누락)
